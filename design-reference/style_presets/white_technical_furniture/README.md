# Белый технический стиль мебели

Переносимый пресет повторяет стиль текущей модели и всех утверждённых экспортов. Он содержит только визуальные параметры и правила оформления — габариты и геометрию следующего предмета мебели нужно задавать отдельно.

## Состав

- `furniture-style-preset.json` — единый источник параметров, удобный для любых программ и генераторов.
- `furniture-style-preset.js` — готовые настройки и функции для интерактивной HTML/Canvas 3D-модели.
- `furniture_style_preset.py` — параметры и функции для генерации SVG и PNG.

## Зафиксированный стиль

- белый фон и белые матовые поверхности;
- видимые рёбра — сплошные чёрные;
- невидимые рёбра — тонкий светло-серый пунктир;
- размерные линии светлее и тоньше линий объекта;
- размерные числа крупные, тёмно-серые, с белой маской под текстом;
- размеры располагаются преимущественно сверху и слева;
- частные размеры ближе к контуру, общие — дальше;
- тени выключены по умолчанию;
- ортографические виды: фасад, сверху и слева;
- максимальная сторона растрового экспорта — 4000 px.

## Подключение к HTML-модели

```html
<script src="furniture-style-preset.js"></script>
<script>
  const style = FURNITURE_TECHNICAL_STYLE;
  FurnitureTechnicalDrawing.applyLayer(ctx, "object");
  FurnitureTechnicalDrawing.applyLayer(ctx, "hidden");
  FurnitureTechnicalDrawing.drawHorizontalDimension(ctx, x1, x2, y, "1800");
  FurnitureTechnicalDrawing.drawVerticalDimension(ctx, y1, y2, x, "800");
</script>
```

Скрытые рёбра следует определять по геометрии новой модели, затем рисовать их слоем `hidden`. Видимые рёбра рисуются поверх слоем `object`.

## Подключение к Python-экспорту

```python
from furniture_style_preset import (
    STYLE,
    draw_dashed_line,
    svg_horizontal_dimension,
    svg_style_block,
    svg_vertical_dimension,
)

svg = f"""<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 2160 1080">
{svg_style_block()}
<rect width="2160" height="1080" fill="{STYLE['background']}"/>
<g class="object">...</g>
<g class="hidden">...</g>
<g class="dimension">
  {svg_horizontal_dimension(220, 2020, 45, "1800")}
  {svg_vertical_dimension(180, 980, 45, "800")}
</g>
</svg>"""
```

При генерации PNG используйте `STYLE` для толщин и цветов, `get_font()` для шрифта и `draw_dashed_line()` для невидимых граней.

## Правила размеров

1. Размеры размещаются вне контура объекта, если это возможно.
2. Каждый размер ставится только один раз.
3. Маленькие размеры располагаются ближе к объекту, общие — дальше.
4. Размеры идут строго по осям, кроме действительно наклонных деталей.
5. Размеры одного конструктивного элемента группируются вместе.
6. Каждый размер привязывается к конкретной детали модели.
7. По возможности используются только две стороны: верхняя и левая.
8. Размерные, выносные и объектные линии не должны создавать нечитаемых пересечений.

Важно: числа `1800` и `800` в примерах показаны только для демонстрации вызова функций. Для следующей мебели подставляйте её фактические размеры.
